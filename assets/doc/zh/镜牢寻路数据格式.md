# 镜牢寻路数据格式

本文对应 `tasks/mirror/search_road.py`，仅记录 Bus 右侧节点、ONNX 节点和道路连接的数据格式。

## Bus 列和右侧节点列

Bus 固定位于 `RouteGraph.columns["column1"]`。`nodes_column` 不包含 Bus；`nodes_column[0]` 是 Bus 右侧的 `column2`，后续元素依次对应 `column3`、`column4`。

外层列表按 X 坐标从左到右排列，内层节点按 Y 坐标从上到下排列：

```python
nodes_column = [
    [  # nodes_column[0]：column2，Bus 右侧第一列
        ["event", (459, 221)],
        ["battle", (458, 548)],
        ["battle", (458, 870)],
    ],
    [  # nodes_column[1]：column3，Bus 右侧第二列
        ["abnormality_focused_encounter", (845, 549)],
        ["event", (845, 864)],
    ],
]
```

## ONNX 节点

格式：

```python
[node_class, (center_x, center_y)]
```

示例：

```python
["battle", (620, 560)]
```

节点类型：

```text
battle
boss_battle
event
focused_encounter
risky_encounter
shop
abnormality_focused_encounter
```

## `divide_the_area_by_x(data)`

输入（假设 `cfg.set_win_size == 1440`）：

```python
data = [
    ["battle", (980, 760)],
    ["battle", (450, 700)],
    ["event", (460, 220)],
]
```

输出：

```python
divide_the_area_by_x(data) == [
    [
        ["event", (460, 220)],
        ["battle", (450, 700)],
    ],
    [
        ["battle", (980, 760)],
    ],
]
```

## `identify_road(bus_position, nodes_column, bus_row)`

`Row.TOP = 1`、`Row.MID = 0`、`Row.BOTTOM = -1`。道路连接格式为 `(column_number, source_position, target_position)`。

输入：

```python
bus_position = (100, 690)
nodes_column = [
    [
        ["event", (620, 253)],
        ["battle", (620, 690)],
    ]
]
bus_row = Row.MID
```

假设 `mid.png` 确认 Bus 与中行 `battle` 相连，输出：

```python
identify_road(bus_position, nodes_column, bus_row) == [
    (1, Row.MID, Row.MID)
]
```

`column_number=1` 表示从 Bus 所在的 `column1` 连向 `nodes_column[0]` 对应的 `column2`。

## `RouteGraph.init_road(connections)`

输入：

```python
connections = [(1, Row.MID, Row.TOP)]
```

调用和输出状态：

```python
route_graph.init_road(connections) is None

route_graph.columns["column1"][Row.MID].next_nodes == [
    route_graph.columns["column2"][Row.TOP]
]
```

该方法没有返回值，只把源节点的 `next_nodes` 指向下一列目标节点；困牢只写入前两列连接。
